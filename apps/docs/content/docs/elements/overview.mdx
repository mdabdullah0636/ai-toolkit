AI TOOLKIT Elements provides 49 ready-to-use UI components for building AI-native application interfaces. Built on top of `@ai-toolkit/shadcn-ui` primitives, these components include conversation containers, message renderers, prompt inputs, canvas diagrams, and more.

These components are unstyled-by-default, building blocks that pair with the hooks in `@ai-toolkit/react` (`useChat`, `useCompletion`) and the types in `ai-toolkit`. Each component exposes `data-slot` attributes for styling with Tailwind CSS.

## Getting Started

```tsx
import { useChat } from '@ai-toolkit/react';
import {
  Conversation,
  Message,
  PromptInput,
  Canvas,
  AgentTools,
  AgentTool,
} from '@ai-toolkit/elements';

export function Chat() {
  const { messages, sendMessage, status } = useChat();

  return (
    <>
      <Conversation />
      <Message />
      <PromptInput
        onSubmit={text => sendMessage({ text })}
        disabled={status === 'submitted' || status === 'streaming'}
      />
    </>
  );
}
```

## Components

### Conversation

Scrollable `role="log"` container. Scrolls to the bottom when children change unless `autoScroll={false}`.

### Message

Renders a `UIMessage` with role-based alignment (user right, assistant left). Text, reasoning, tool-invocation, source, and file parts have default renderings; override any part with `renderPart`, add an `avatar`.

### PromptInput

Chat input form. Enter submits, Shift+Enter inserts a newline. Works controlled (`value`/`onChange`) or uncontrolled (`defaultValue`). Empty submissions are ignored and the input clears after submit in uncontrolled mode.

### Canvas

React Flow-based diagram canvas using `@xyflow/react`. Supports nodes, edges, and temporary edge preview. Requires the xyflow stylesheet to be loaded (see [Prerequisites](/docs/ai-toolkit-elements/prerequisites)).

### AgentTools / AgentTool

Displays a tool accordion with `type="multiple"` by default. Each `AgentTool` renders a tool description, schema (JSON), and input schema editor.

### Prerequisites

- React 18+ (peer dependency)
- Tailwind CSS in your app (components ship unstyled `data-slot` hooks with Tailwind utility classes; bring your own stylesheet to restyle)
- `@xyflow/react` CSS: add `<link rel="stylesheet" href="https://unpkg.com/@xyflow/react/dist/style.css">` to style the flow renderer

## Styling

Every element exposes `data-slot` attributes (`conversation`, `message`,
`message-text`, `message-reasoning`, `message-tool`, `message-source`,
`message-file`, `message-avatar`, `message-content`, `prompt-input`,
`prompt-input-textarea`, `prompt-input-submit`) plus `data-role` and
`data-state` where relevant, so you can restyle without Tailwind.

Components are deliberately unstyled — `data-slot` hooks let you override
colors, spacing, and layout using your own Tailwind classes or CSS.

## Development

- Run `pnpm build` to rebuild `@ai-toolkit/shadcn-ui` and `@ai-toolkit/elements`.
- Run `pnpm type-check` to verify TypeScript types.
- Run `pnpm test` to run Vitest jsdom tests.
- Run `pnpm prettier-fix` to apply the repo's single‑quote / no‑semi formatting.

## Registry

The `registry.json` file at the package root lists all 49+ components with their source paths, titles, descriptions, and dependencies. It can be consumed by the shadcn CLI for `pnpm dlx shadcn add` integration.
