## Issue

I am using [`useChat`](/docs/reference/ai-toolkit-ui/use-chat) or [`useCompletion`](/docs/reference/ai-toolkit-ui/use-completion), and I am getting a `"Failed to parse stream string. Invalid code"` error. I am using version `3.0.20` or newer of the AI TOOLKIT.

## Background

The AI TOOLKIT has switched to the stream data protocol in version `3.0.20`.
[`useChat`](/docs/reference/ai-toolkit-ui/use-chat) and [`useCompletion`](/docs/reference/ai-toolkit-ui/use-completion) expect stream parts that support data, tool calls, etc.
What you see is a failure to parse the stream.
This can be caused by using an older version of the AI TOOLKIT in the backend, by providing a text stream using a custom provider, or by using a raw LangChain stream result.

## Solution

You can switch [`useChat`](/docs/reference/ai-toolkit-ui/use-chat) and [`useCompletion`](/docs/reference/ai-toolkit-ui/use-completion) to raw text stream processing with the [`streamProtocol`](/docs/reference/ai-toolkit-ui/use-completion#stream-protocol) parameter.
Set it to `text` as follows:

```tsx
const { messages, append } = useChat({ streamProtocol: 'text' });
```
