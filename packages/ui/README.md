# UI Layer

React component library for AI-native applications (AI Elements), distributed as
an npm package and a shadcn registry. Components are unstyled-by-default
building blocks that pair with the hooks in `packages/adapters/react/`.

**Owner**: @khulnasoft/ai-react-team

| Package    | npm name               | Purpose                                     |
| ---------- | ---------------------- | ------------------------------------------- |
| `elements` | `@ai-toolkit/elements` | Conversation, message, and input components |
